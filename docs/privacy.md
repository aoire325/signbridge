# Privacy

- Camera permission is requested only after the user taps the start action.
- Native camera buffers are analyzed on-device. Only landmarks cross into JavaScript; up to 200 landmark samples are held briefly for isolated-word recognition, or up to 400 native samples resampled to 96 / 12 seconds for sentence translation. Sentence landmark buffers are cleared after translation, cancellation, interruption or leaving the mode. No photos or video files are created by this flow. Native model weights may stay cached for 30 seconds after stopping; no app-owned camera frames are retained in that cache.
- Personal signs and Recognition Lab are optional. Tapping Record example collects one feature sequence; only Save example persists it in the app's Documents directory (`signbridge-examples-v1.json`, up to 120 records). Records contain normalized hand/body/face features, observation masks, timing, expected label, signer nickname, session/split, gesture-version IDs, available predictions, per-model leaders and capture diagnostics. Empty predictions explicitly indicate unavailable model output. Facial geometry is sensitive even without video; use pseudonyms and export only recordings you intend to share. Ordinary signing does not save examples. Personal learning uses these local features; no server receives them. Save & use this version saves the active signer and enabled setting in the same file, so the profile can be rebuilt locally on reopening the camera screen. Turning personal learning off persists that choice. Deleting examples clears the active profile.
- Remove last and Delete all remove saved examples; Delete all also clears a failed-write temporary file. Export examples writes a JSON file to the folder explicitly chosen in the system picker. Copies in that folder are outside the app's Delete all action; a cloud-backed folder may sync according to the user's file-provider settings. Nothing is automatically exported or uploaded.
- In translator mode, camera frames are not uploaded and video is not recorded. In video calls, the local camera stream and any enabled microphone audio are transmitted to the invited guest using WebRTC. A TURN relay may carry encrypted traffic when a direct connection is unavailable. SignBridge does not record calls or log image data.
- Microphone access is optional. It is requested when the caller chooses to enable audio; calls start muted by default. Signing and typed captions do not require microphone permission.
- Call invitations are randomly generated bearer codes for two-person rooms. The signaling service sees display names, connection metadata, and network addresses. It keeps rooms in memory, does not persist call records or captions, and expires invitations after 15 minutes of waiting. Display names are not verified identities. Operational proxy logs are controlled by the deployment operator.
- AI caption recognition runs locally on the same video frames used by the call. Landmark features are not sent to the guest or signaling server. Reviewed captions, explicitly enabled automatic AI guesses, and typed captions are sent over the encrypted peer data channel. Automatic guesses are labeled unreviewed. SignBridge holds the latest captions in memory and clears them at hang-up.
- The transcript exists only in memory during the current app session. It is not stored as history and is cleared when the app process ends.
- Copying text explicitly places the selected transcript on the system clipboard.
- Translator camera use pauses when the app backgrounds or the user leaves the camera screen. Video calls end when the app backgrounds or the caller leaves the call screen; their media tracks are released.

The calling feature has a signaling backend; it does not perform AI inference. The sentence encoder and English decoder remain bundled local models. Translation does not upload landmarks or unfinished drafts. Release builds do not fall back to a model-download server. Model inference runs locally with TensorFlow Lite. See [calling setup](calling.md) for service configuration and deployment boundaries.
